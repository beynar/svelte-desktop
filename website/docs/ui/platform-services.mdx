All of these are on `host`, from page and server code. Ops a platform can't provide reject with `unsupported`; `host.capabilities.describe()` lists what the running build supports. In server startup code, register native work with `host.ready(() => { /* native calls */ })`; see [threads and processes](/native/threads). Each section links to the reference page with every option.

## Dialogs

Open, save and message dialogs, plus `sheet(route)` to show a route of your app as a dialog and get a result back. [`host.dialog`](/host/windows/dialog)

```ts
const { canceled, paths } = await host.dialog.showOpenDialog({ multiple: true });
const board = await host.dialog.sheet<{ name: string }>('/sheets/new-board', { width: 420, height: 230 });
// the sheet's page ends with: host.dialog.close({ name })
```

### Security-scoped file bookmarks (macOS)

For sandboxed builds: ask the open dialog for `securityScoped: true`, keep the returned bookmark, and reopen it on a later launch with [`host.files`](/host/os/files).

```ts
const { bookmarks } = await host.dialog.showOpenDialog({ directories: true, files: false, securityScoped: true });
const access = await host.files.openBookmark(bookmarks![0]);
try { await useFolder(access.path); } finally { await access.release(); }
```

## Clipboard

Read and write text, HTML, RTF, images and file paths, or several representations in one copy. [`host.clipboard`](/host/input/clipboard)

```ts
await host.clipboard.writeText('Hello');
```

## Shell

Open links and files in their default app, reveal or trash items, share, drag files out of the page, and Quick Look previews. [`host.shell`](/host/os/shell)

```ts
await host.shell.openExternal('https://svelte.dev');
await host.shell.showItemInFolder('/Users/me/report.pdf');
```

## Theme

Follow or set the light and dark theme; `host.theme.dark` is reactive. [`host.theme`](/host/app/theme)

```svelte
<div class:dark={host.theme.dark}>...</div>
```

## System

The OS, architecture, keyboard layout, accent color, accessibility settings and Touch ID availability. [`host.system`](/host/app/system). Permissions have their own page: [Permissions](/features/permissions).

## Power

Keep the Mac awake during long work, read the battery, and react to sleep, wake, lock and shutdown. [`host.power`](/host/app/power)

```ts
await using blocker = await host.power.acquireSleepBlocker({ type: 'display', reason: 'Exporting' });
```

## Screens

The attached displays, their bounds and scale, and the cursor position. [`host.screen`](/host/app/screen)

## Secure storage

Secrets in the system keychain, never a plaintext fallback, and a Touch ID or password prompt before sensitive actions. [`host.secureStorage`](/host/os/secure-storage)

```ts
await host.secureStorage.setPassword('com.example.notes', 'api-token', token);
const { authenticated } = await host.secureStorage.authenticate('Unlock your notes');
```

## Global shortcuts

Hotkeys that work while the app is in the background. [`host.shortcuts`](/host/input/shortcuts)

```ts
await host.shortcuts.register({ accelerator: 'CmdOrCtrl+Shift+K', id: 'quick' });
host.shortcuts.onPressed(({ id }) => { if (id === 'quick') host.window.show(); });
```

## Deep links and documents

URLs for your scheme and documents of your file types, delivered to a running or cold-launched app. Declare `schemes` and `fileTypes` in [`desktop.config.ts`](/reference/config). [`host.deepLink`](/host/app/deep-link) for URLs, [`host.webview`](/host/web/webview) for `onOpenFiles` and `getOpenedFiles`.

```ts
host.deepLink.onOpen(({ urls }) => { /* svelte-notes://... */ });
```

## App and Dock

Quit and relaunch, Dock badge, bounce, icon and progress, launch at login, the About panel and standard folders. Server code also has `host.paths` for databases and files. [`host.app`](/host/app/app)

```ts
host.app.setDockBadge('3');
```

## Status item from code

The [`StatusItem` component](/ui/menu-bar-and-popovers) covers most needs. To drive the menu bar item directly, use [`host.tray`](/host/input/tray).

## Key-value store

A small persisted JSON record, kept in your app's own data folder. For anything relational, use `bun:sqlite` in server code with `host.paths.data`. [`host.store`](/host/data/store)

```ts
host.store.set('lastOpened', '/Users/me/notes.md');
const last = host.store.get<string>('lastOpened');
```

## Screen capture

List displays and windows and grab a still image, after checking `host.capture.isSupported()`. Needs the Screen Recording [permission](/features/permissions) on macOS. [`host.capture`](/host/os/capture)
