---
title: Menu bar and popovers
description: Status items, routes in native popovers, and Spotlight-style panels on a global shortcut.
---

A popover is **a route of your SvelteKit app** shown in a native macOS popover (with the arrow) or in a borderless translucent panel. It runs in its own web view with the same server, session cookie, remote functions and `host` API as the main window.

## 1. Write the route

Keep popover routes in their own group so they don't inherit the window's layout:

<FileTree>

- src/routes/
  - +layout.svelte
  - (app)/
    - +layout.svelte
    - +page.svelte
  - (popover)/
    - +layout.svelte
    - quick/
      - +page.svelte

</FileTree>

```svelte src/routes/(popover)/quick/+page.svelte
<script lang="ts">
  import PopoverContent from '@svelte-desktop/shell/platform/PopoverContent.svelte';
  import { addNote } from '$lib/data.remote';
</script>

<!-- transparent page, and the popover is sized to this content -->
<PopoverContent>
  <h3>Quick note</h3>
  <form {...addNote.enhance(async ({ submit }) => { await submit(); await host.broadcast('notes-changed'); })}>
    <input {...addNote.fields.text.as('text')} />
  </form>
  <button onclick={() => host.closePopover()}>Done</button>
</PopoverContent>
```

`PopoverContent` props: `fit` (`height`, the default, keeps the given width and follows the content height; `both` also uses the content width; `none`), `padding`, `class`.

## 2. Open it

### From the menu bar

```svelte src/routes/(app)/+layout.svelte
<script>
  import StatusItem from '@svelte-desktop/shell/platform/StatusItem.svelte';
</script>

<StatusItem icon="note.text" tooltip="Quick note" popover={{ route: '/quick', width: 320 }} />
```

```svelte
<StatusItem icon="note.text" popover="/quick" bind:open />                    <!-- route string -->
<StatusItem icon="bolt" style="panel" popover="/palette" position="tray" />     <!-- panel under the icon -->
<StatusItem icon="note.text" items={[{ label: 'Quit', role: 'quit' }]} />       <!-- a menu instead -->
<StatusItem icon="note.text" onClick={() => host.window.show()} />              <!-- plain click -->
```

Clicks toggle the popover natively, with no round trip through the page, and a click that dismissed a transient popover never reopens it.

A menu-bar-only app sets `trayOnly: true` (no Dock icon, no app menu) and `window: false` or `window: { visible: false }` in `desktop.config.ts`.

### Anchored to an element

```svelte
<script>
  import Popover from '@svelte-desktop/shell/platform/Popover.svelte';
  let button = $state(), open = $state(false);
</script>

<button bind:this={button} onclick={() => (open = !open)}>Emoji</button>
<Popover route="/emoji" anchor={button} bind:open width={260} height={120} edge="bottom" />
```

### A panel on a global shortcut

The shortcut works while the app is in the background:

```svelte
<Popover route="/palette" style="panel" position="center" shortcut="Ctrl+Alt+Space" width={520} />
```

### From code

```ts
await host.popover.create({ id: 'quick', route: '/quick', width: 320, tray: true });
await host.popover.show('quick', { anchor: 'cursor' });
await host.popover.toggle('quick');
await host.popover.hide('quick');
host.popover.onShown(({ id }) => {});
host.popover.onHidden(({ id }) => {});
```

`anchor` is `'tray'`, `'cursor'`, a rect in the page (`{ x, y, width, height }`, CSS px, e.g. from `getBoundingClientRect()`) or `{ screen: { x, y, width, height } }`. Other ops: `setSize`, `setPosition`, `isShown`, `get`, `list`, `eval`, `reload`, `destroy`, and the `onReady` and `onResized` events.

## Talking to the main window

Each popover is a separate page. Share state through:

- **the server**: remote functions hit the same Bun process and database;
- **the stores**: every page receives native events (`host.theme.dark`, `host.window.*`, ...);
- **broadcast**: `host.broadcast('channel', data)` and `host.onBroadcast('channel', fn)` reach every window, popover and server code.

Inside a popover, `host.currentPopover()` returns `{ id }`, `host.closePopover()` closes it, and every `host.popover` op defaults to the current popover.

## Built in

- **Instant first open.** The web view is created and loaded at `create` and kept warm.
- **Sized to content.** `PopoverContent` reports its size; the popover follows.
- **No white flash.** The page is transparent and the native material shows through.
- **Light dismiss.** Transient popovers close on an outside click; panels on an outside click, when another window takes focus, or when they lose key status. Escape closes the focused popover.
