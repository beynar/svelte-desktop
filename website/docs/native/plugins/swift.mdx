Swift plugins run inside the shell process, on macOS only. Use them for Apple frameworks and AppKit work that needs the main thread. For portable native code, use [Rust or Go](/native/plugins); for work that needs its own process, use a [sidecar](/native/sidecars) or [service](/native/services). Keep Swift files under `native/macos/`: other platforms skip or fail on them (see [Platforms](/native/plugins/platforms)). Shared rules (names, errors, events, `bridge.allow`, dev restarts) are on [Plugins](/native/plugins).

## Quick start

Create `native/macos/Commands.swift`. The build supplies `Desktop` alongside your sources, so there is no SDK module to import. Define exactly one `desktopSetup()` across your Swift files and register commands there.

```swift native/macos/Commands.swift
import AppKit

struct FindAppArgs: Codable {
  let bundleId: String
}

struct InstalledApp: Codable {
  let name: String
  let path: String
}

func desktopSetup() {
  Desktop.command("os.findApp") { (args: FindAppArgs) -> InstalledApp? in
    guard !args.bundleId.isEmpty else {
      throw DesktopError.invalidArgs("bundleId must not be empty")
    }
    guard let url = NSWorkspace.shared.urlForApplication(
      withBundleIdentifier: args.bundleId
    ) else { return nil }
    return InstalledApp(
      name: url.deletingPathExtension().lastPathComponent,
      path: url.path
    )
  }

  Desktop.command("os.windowTitle") { () -> String? in
    Desktop.window()?.title
  }
}
```

Call these from a page or SvelteKit server code:

```ts
import { native } from '@kitop/shell/native';

const app = await native.os.findApp({ bundleId: 'com.apple.TextEdit' });
// { name: string; path: string } | null

const title = await native.os.windowTitle(); // string | null
```

`host.native` is the same without an import. Swift sends events with `Desktop.emit`; pages and server code receive them with [`host.on`](/host/data/events).

### Commands

All three `Desktop.command` overloads take an `@MainActor` closure that may be `async` and may `throw`:

| Registration | Arguments and result |
| --- | --- |
| `Desktop.command("service.op") { (args: Args) in … }` | `Args` is `Decodable`, the result `Encodable`. Decoding failures reject with `invalid_args`. |
| `Desktop.command("service.op") { () -> Result in … }` | No arguments (incoming ones are ignored); the result is `Encodable`. |
| `Desktop.command("service.op") { (args: [String: Any]) -> Any? in … }` | Raw dictionary arguments and a JSON-compatible result. TypeScript gets `Record<string, unknown>` and `Promise<unknown>`. |

Return a JSON value such as `Bool`, not `Void`, from a typed command. A name without `service.op` form fails a Swift precondition.

## Type mapping

During dev and macOS packaging, the build reads the commands in a subprocess and writes `src/native.d.ts`. Swift shapes are found by running `Decodable.init(from:)` against a recording decoder, so use `Codable` models for both arguments and results.

| Swift model | Generated TypeScript |
| --- | --- |
| `String`, `URL`, `UUID` | `string` |
| `Bool` | `boolean` |
| Integer and floating-point types | `number` |
| `Date` | `number`, with the default `JSONEncoder` date strategy |
| A synthesized `Codable` struct | An inline object |
| `let name: String?` property | `name?: string \| null` |
| `String?` result | `string \| null` |
| `[String]` | `string[]` |
| `[String: Int]` | `Record<string, number>` |
| A string-backed `Codable, CaseIterable` enum | A union of its raw values |
| An `Encodable`-only result | `unknown` |
| The raw dictionary overload | `Record<string, unknown>` arguments; `unknown` result |

Custom decoding, validation that rejects placeholder values, recursive models (nesting stops at depth 12) and other enums can give `unknown` or incomplete shapes. Check `src/native.d.ts` for such models. A JavaScript `number` can't hold every 64-bit integer.

## Slow work without freezing the window

Command bodies run as main-actor tasks. File I/O, CPU loops and sleeps in them block AppKit, and `async` alone doesn't move them off the main thread; a `Task { … }` inside the handler inherits the actor too. Await APIs that suspend. Move blocking work into `Task.detached` with value data, and use `await MainActor.run` to touch AppKit again. See [threads and processes](/native/threads).

This example hashes a file in chunks and broadcasts progress. Add it as a second file, then call `registerHashCommands()` from your `desktopSetup()`.

```swift native/macos/Hash.swift
import Foundation
import CryptoKit

struct HashArgs: Codable, Sendable {
  let path: String
  let jobId: String
}

struct HashResult: Codable, Sendable {
  let sha256: String
  let bytes: Int
}

func registerHashCommands() {
  Desktop.command("files.hash") { (args: HashArgs) -> HashResult in
    guard args.path.hasPrefix("/"), !args.jobId.isEmpty else {
      throw DesktopError.invalidArgs("Supply an absolute path and a jobId")
    }
    let path = args.path
    let jobId = args.jobId

    return try await Task.detached(priority: .utility) {
      () async throws -> HashResult in
      let file = try FileHandle(forReadingFrom: URL(fileURLWithPath: path))
      defer { try? file.close() }
      var hasher = SHA256()
      var processed = 0

      while let chunk = try file.read(upToCount: 1_048_576), !chunk.isEmpty {
        hasher.update(data: chunk)
        processed += chunk.count
        let bytes = processed
        await MainActor.run {
          Desktop.emit("files.hashProgress", [
            "jobId": jobId,
            "processedBytes": bytes
          ])
        }
      }

      let digest = hasher.finalize()
      return HashResult(
        sha256: digest.map { String(format: "%02x", $0) }.joined(),
        bytes: processed
      )
    }.value
  }
}
```

Subscribe before starting the command, and remove the listener even if it fails:

```ts
import { native } from '@kitop/shell/native';

async function hashFile(path: string) {
  const jobId = crypto.randomUUID();
  const off = host.on<{ jobId: string; processedBytes: number }>(
    'files.hashProgress',
    (progress) => {
      if (progress.jobId === jobId) console.log(progress.processedBytes);
    }
  );
  try {
    return await native.files.hash({ path, jobId });
    // { sha256: string; bytes: number }
  } finally {
    off();
  }
}

const selection = await host.dialog.showOpenDialog();
if (!selection.canceled && selection.paths[0]) {
  console.log(await hashFile(selection.paths[0]));
}
```

`jobId` separates concurrent requests, because events are broadcast. Removing a listener doesn't cancel the task, and there is no cancellation parameter. Use a [background job](/native/jobs) or [sidecar](/native/sidecars) when work must survive a crash or be cancelled.

## Events, logging and errors

`Desktop.emit(_ event: String, _ data: Any? = nil)` can be called from any thread; delivery is dispatched to the main queue. It uses Foundation JSON serialization, not `JSONEncoder`: pass dictionaries, arrays and scalars, not `Codable` structs. A dictionary is the payload; anything else, including `nil`, arrives as `{ value: … }`.

```swift
Desktop.emit("sync.progress", ["completed": 3, "total": 10])
Desktop.emit("sync.finished") // listener receives { value: null }
Desktop.log("Sync finished")    // NSLog, prefixed [native plugin]
```

Throw a `DesktopError` to reject the promise:

| Swift error | JavaScript error code |
| --- | --- |
| `DesktopError.invalidArgs(message)` | `invalid_args` |
| `DesktopError.unsupported(message)` | `unsupported` |
| `DesktopError.unavailable(message)` | `unavailable` |
| `DesktopError.denied(message)` | `denied` |
| `DesktopError.failed(message)` | `internal` |
| Any other thrown `Error` | `internal`, with `String(describing: error)` as the message |

Framework errors don't become `denied` or `unavailable` on their own: translate them if callers need that. Swift traps and precondition failures aren't thrown errors.

## AppKit windows and permissions

`@MainActor Desktop.window(_ id: Int = 0) -> NSWindow?` returns a shell-owned window, or `nil`. `0` is the main window (the first remaining one); a positive value is that public window ID. It doesn't pick the caller's window, so pass a window ID in your arguments for multi-window commands. Fetch the window when you need it, especially after an `await`: it may have closed. For the web view, use the [webview Host API](/host/web/webview).

A plugin is privileged native code: validate paths and sizes inside it. OS consent is separate from `bridge.allow`: declare protected capabilities under `permissions` in [`desktop.config.ts`](/reference/config) and request access through the Apple API or [`host.permissions`](/host/os/permissions).

## Build

All Swift files plus the shipped `Kitop.swift` compile together as one `AppNative` module (Swift 5 language mode), linked with any C-family objects into `libapp-native`. You need a Swift toolchain and the Apple SDK. Imported framework modules autolink. `desktopSetup()` runs on the UI thread before the run loop starts and also when the build reads the commands, with no window or app: keep it to registration. A command not registered on the current platform rejects with `unknown`.
