```ts desktop.config.ts
import { defineConfig } from '@svelte-desktop/shell/config';

export default defineConfig({ appName: 'Notes', identifier: 'com.example.notes' });
```

`defineConfig` takes `DesktopConfig`: `appName` and `identifier` are required by that type. The loader also accepts a partial config and applies the fallbacks below. Optional fields have no configured value unless a default is shown. Nested defaults, such as permission reasons and foreground notification banners, still apply when their parent object is omitted.

There are no `jobs` or `services` config keys. These are discovered from `src/jobs/` and `src/services/`; see [jobs](/native/jobs) and [services](/native/services). See [Native code](/native) for plugins, addons and sidecars.

### icon

The object form accepts `source: string` (required, relative to the project) and `background?: string` (hex color). `background` defaults to the artwork's corner color for opaque-cornered images, otherwise white. It controls the background of the macOS 26 icon. See [App icon](/shipping/app-icon).

## permissions

`PermissionsConfig` is `Partial<Record<PermissionName, string | false>>` with a string index signature accepting `string | string[] | false | undefined`, plus the deprecated `pages` field.

<TypeTable
  type={{

    "[usageKey]": { type: "string | string[] | false | undefined", description: "Raw `NS…UsageDescription` string values pass through to Info.plist. The index signature also accommodates the legacy `pages` array." },
    pages: { type: "string[]", description: "Deprecated: use `bridge.allow`. Used only when `bridge.allow` is absent." },
  }}
/>

`PermissionName` is `camera`, `microphone`, `location`, `contacts`, `calendars`, `reminders`, `photos`, `bluetooth`, `speech`, `appleEvents`, `notifications`, `screenRecording`, `accessibility`, `inputMonitoring`, `fullDiskAccess`, `desktopFolder`, `documentsFolder` or `downloadsFolder`. See [Permissions](/features/permissions).
