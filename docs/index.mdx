**svelte-desktop** explores a single question: *can a Svelte app render to real native UI — GPUI, the Rust engine behind the Zed editor — while keeping Svelte's authoring model intact?*

The answer so far is **yes — and further than the language.** Svelte 5
(45/45 cases), SvelteKit semantics (49/49 — routing, `load`, hooks, remote
functions, forms, streaming), a ~45-component native kit (`nkit`, 30/30),
two renderer backends, and a packaged `.app`/single binary that opens a real
GPUI window. All verified by hit-testing, not synthetic DOM events.

```txt
.svelte file → svelte/compiler → compiled client JS
                                    │
                                    ▼
                        fake DOM (gdom.ts)
                                    │  createElement / setStyle /
                                    ▼  setText / insertBefore / …
                        gpuix applyBatch protocol
                                    │
                                    ▼
                    GPUI (Rust) → Metal → native window
```

## Status at a glance

| | |
|---|---|
| Svelte runtime | **45/45** headless on `TestGpuixRenderer`; same cases on the QuickGUI backend |
| SvelteKit layer | **49/49** — routes/params/matchers, layouts, `load`, hooks, actions, `use:enhance`, remote `query`/`command`/`form`, streaming, `$app/*` |
| nkit | **30/30** — ~45 themed native components + 25-page showcase |
| Remote functions | Real request semantics: through `hooks.handle` with a synthesized RequestEvent — backed by `bun:sqlite` |
| Live window | `bun src/main.ts`; median first tick **293 ms** over 20 packaged launches |
| Headless testing | Deterministic: real hit-testing, keystrokes, painted-text asserts |
| Packaging | **Works** — 82.6 MB single binary + `.app` bundle (`bun run package`) |
| Multi-window | Functional on the QG backend; teardown segfault is a known blocker |
| Platform | macOS arm64 only — no Windows/Linux claims |

:::warning
This is a hardened research alpha, not a library. The code lives in
`gpuix-poc/`; the [recommendation report](https://github.com/) is the honest
release-blocker list. A real `svelte-gpuix` package is the [roadmap](/roadmap).
:::
